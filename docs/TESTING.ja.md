# 実機確認（未実行）

以下はWindowsとSteamでゲームを所有する2人以上で実行する確認手順です。クラウド環境では実行していません。

1. 新しいテスト用セーブを作成し、共有残高を記録して終了する。全員が自動読み込み版を配置し、Steamから起動する。ホストがそのセーブを開く。プレイ画面に「F8 ウォレット」が表示され、F8でゲーム内パネルが開くことを確認する。外部ウィンドウが開かないことも確認する。
2. 初回はホストだけに既存残高が入り、参加者は0で開始することを確認する。全員の画面が「同期済み」になることを確認する。
3. ホストから参加者へ12.50送金する。送金元が12.50減り、送金先が12.50増え、合計額が変わらないことを確認する。
4. 参加者からホストへ0.01送金する。逆方向でも同じように同期することを確認する。
5. 残高不足、0、負数、3桁以上の小数、自己送金、退出した相手への送金が成立しないことを確認する。
6. ホストと参加者それぞれで区画清掃、搬入／打ち上げ、トリックを行う。対象者の財布だけがゲーム本来の報酬分増えることを確認する。両者が搬入した場合の精算も確認する。
7. 装備、コンテナー、ツリー、乗り物、車両強化、建設、ベルト、ランドマーク、テレポートを両者で実行し、実行者だけが払うことを確認する。高残高のホストと低残高の参加者を用意し、参加者がホストのお金では購入できないことを確認する。
8. 購入直後に別の購入や送金を連続操作し、確認応答前は次の操作が待機することを確認する。
9. 送金中に通信を一時切断して戻し、同一要求で1回だけ引き落とされることを確認する。ホストを再起動した場合は旧要求が自動で再実行されないことを確認する。
10. 保存して全員終了し、再度Modを起動して同じセーブへ入り、残高が保持されることを確認する。別スロットへ切り替えて残高が混ざらないことも確認する。
11. 全員退出後、バックアップしたテストデータを使って `MoonWallet-v1.dat` のコピーを破損させ、次の起動で警告され、初期化されないことを確認する。元のファイルに戻す。
12. 別バージョンのゲームでの適用が拒否されること、再起動のたびにEXE操作なしで読み込まれることを確認する。
13. `MoonWallet/disabled.txt` を作成して再起動し、Modの適用が止まり、Windows本来のバージョン情報取得が継続することを確認する。ゲーム終了後にdisabled.txtを削除する。

不具合を報告する場合は、`MoonWallet/loader.log` と `MoonWallet/plugins/MoonWallet.log`、ホスト／参加者のどちらか、操作と金額、操作前後の残高を添えてください。ゲームのセーブやSteam認証情報の公開は不要です。


## ゲーム内UIの追加確認（未実行）

- 1280×720、1920×1080、2560×1440、ウルトラワイドでパネルとボタンが画面内に収まること。
- ゲームのショップと同じ字体・パネル・ボタンで表示され、日本語と長いSteam名が読めること。
- F8・Esc・閉じるボタンで開閉でき、閉じた直後にマウスの視点操作、移動、装備操作が復帰すること。
- 入力中に文字入力がチャット・移動・建設へ流れず、ウォレットの金額欄だけへ入ること。チャット・ポーズメニューからフォーカスを奪わないこと。
- 名前の選択、金額の直接入力、100／500／1,000／全額、送金後残高、確認から修正への復帰を確認すること。
- Enterで確認画面へ進んでも送金は確定しないこと。二重クリックでも送金が1回であること。
- 確認中に相手が退出しても別の相手へ切り替わらず、選択画面へ戻ること。
- 6人以上では一覧がページ送りでき、名簿の順序が変わっても選択相手のIDが維持されること。
- 送金中にパネルを閉じ、完了後に再度開いた場合も結果と最新残高が確認できること。
- 別セーブ・タイトル復帰で前の入力状態が混ざらず、不要なEventSystemが残らないこと。
