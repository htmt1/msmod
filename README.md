# Moon Wallet — Moon Sweepers 個人ウォレットMod

**v0.3.1 ゲーム内UI版・実機検証前の試験版 / Windows 64bit専用**

共有所持金をSteam IDごとの個人残高に分け、同じロビーの参加者へ金額を指定して送金するネイティブModです。添付されたUnity 6000.6.0f1のゲームビルド専用です。ゲーム更新でバイナリが変わった場合は読み込みを拒否します。

## ダウンロード

[ワールド読み込み時のクラッシュ修正版 v0.3.1 ZIP](https://github.com/htmt1/msmod/raw/refs/heads/moonwallet-v0.3.1-world-crash-fix/downloads/MoonWallet-v0.3.1.zip)

v0.3.1では、ワールド読み込み後にUIを作成する際、Unityの64bit GCハンドルを32bitへ切り詰めていた不具合を修正しました。ゲーム本体の64bit APIと照合し、上位32bitを持つハンドルの保持・参照・解放をC++単体テストとWindows x64機械語エミュレーションで確認しています。修正後のWindowsゲーム実機での再確認はまだ行っていません。

## 導入・起動（EXE不要）

1. ゲームを終了します。最初は新しいテスト用セーブを使ってください。既存セーブを使う場合は、セーブスロットのフォルダー全体を別の場所へコピーしてください。
2. ZIP内の **version.dll** と **MoonWalletフォルダー** を、`MoonSweepers.exe` と同じフォルダーへコピーします。配置は以下のとおりです。

```text
Moon Sweepers/
├ MoonSweepers.exe                ← 既存のゲーム
├ GameAssembly.dll               ← 変更しない
├ version.dll                    ← 今回追加する専用ローダー
└ MoonWallet/
   └ plugins/
      └ MoonWallet.dll           ← ウォレット本体
```

3. Steamから普段どおりゲームを起動し、セーブを読み込みます。**別のEXEや外部ウィンドウは不要です。** プレイ画面に「F8 ウォレット」が表示されます。
4. 次回からもSteamから起動するだけです。マルチプレイでは、**ホストと参加者の全員に同じ版を配置**してください。

**v0.2／v0.3.0から更新する場合は、ゲーム終了後に、このModの `version.dll` と `MoonWallet/plugins/MoonWallet.dll` を上書きしてください。既存の個人残高データはそのまま使います。**

前版の `MoonWallet.exe` は不要です。旧版の `MoonWallet.dll` をゲーム直下にも置いていた場合は、旧版の2ファイルを削除してから上記の配置に変更してください。ゲーム本来のDLLは置き換えません。

**別のModローダーの `version.dll` がある場合は上書きしないでください。** MelonLoader等の既存ローダーが使っている可能性があります。その場合はローダー名・バージョンに合った接続方法が必要です。

この版はBepInEx用のマネージドプラグインではなく、専用ローダーとネイティブプラグインの組み合わせです。`BepInEx/plugins` やゲーム標準の `MoonSweepers_Data/Plugins` に本体DLLだけを入れても読み込まれません。BepInEx本体の同梱・対応確認はしていません。

Unity/Windowsがゲームフォルダー内の `version.dll` を読み込む構成を前提にしています。このゲームのUnityPlayer.dllは提供されていないため、実際の自動読み込み経路はWindows実機での確認が必要です。ロードできた場合は `MoonWallet/loader.log` が作成され、本体の処理は `MoonWallet/plugins/MoonWallet.log` に記録されます。

## 操作（ゲーム内で完結）

- **F8**：プレイ画面でウォレットを開く・閉じる。画面の「ウォレット」ボタンからも開けます。
- 左の参加者一覧から**名前で送金先を選択**します。選択中の相手はゲームと同じオレンジのボタンで表示します。長い名前は縮小・省略し、選択後にSteam IDも確認できます。
- 金額を直接入力するか、**100／500／1,000／全額**を選びます。「全額」は送金可能な小数第2位までで計算します（1回の上限あり）。
- **送金後の残高**を見て「内容を確認」へ進み、相手と金額を再確認して「送金を確定」を押します。
- 金額入力中のEnterは確認画面へ進む操作です。**Enterだけで送金を確定しません。**
- **Esc**：確認画面では修正へ戻り、それ以外はウォレットを閉じます。F8でも閉じられます。
- 送金中は二重操作を防ぎ、完了・失敗を同じ画面に表示します。画面を閉じても保留中の通信は続きます。

ゲームのショップと同じ **MoonWorkshopKitのパネル、コイン、フォント、配色、ボタン、ホバー表示**を利用しています。独自のWindows画面やOSの送金確認ダイアログは使用しません。画面を開いている間はプレイヤーの操作を抑止し、閉じるとカーソル・操作状態を戻します。チャットや既存メニューを開いている場合は、先にそちらを閉じてください。マルチプレイ全体の時間は停止しません。

送金額は0.01以上、小数第2位までです。1回の上限は999,999,999,999.99です。残高不足・無効な金額・同期待ちの場合は理由を表示し、確認へ進めません。確認中に相手が退出した場合は送金先を選び直す画面へ戻ります。通信が途切れた場合は同一要求を再送し、二重に引き落とさない仕組みです。

## お金の扱い

- 初回導入時の既存共有残高は、**全額をホストの個人財布へ1回だけ移行**します。人数分には複製しません。必要に応じてホストから参加者へ送金してください。
- 清掃区画報酬・搬入／打ち上げの精算・トリック報酬は、ゲームが指定する対象プレイヤーの財布へ入れます。報酬の総額や貢献の計算式はゲーム側を利用します。
- 装備・アップグレード・乗り物・建設・テレポートなどの費用は、対象プレイヤー自身の残高で判定・引き落としします。
- プレイヤーに帰属しない旧施設の一括撤去補償はホストへ入ります。
- 残高は**セーブスロットごと**に保存し、退出した参加者の残高も保持します。別のホストや別セーブへの持ち出しは行いません。
- 同期が済むまで購入と送金を待機させます。参加者は購入の確認応答が届くまで次の購入を待ちます。

## 保存と解除

ホストのゲームセーブフォルダーに `MoonWallet-v1.dat` を作成します。更新前のファイルは `.bak`、書き込み途中のものは `.tmp` です。送金は残高2件と再送判定情報を同じファイルに保存してから確定します。ファイルを読み込めない場合は自動で初期化せず停止します。

`MoonWallet-v1.dat` はゲーム本来のセーブとは別ファイルです。両者をまとめてバックアップ・復元してください。ゲーム本来のセーブと個人財布の書き込みを1つのトランザクションにする機能はありません。セーブ中の強制終了時の整合性は実機確認が必要です。

通常のゲームセーブには個人財布の合計残高を渡します。Modを使わずに起動した場合は、そのゲームセーブ時点の合計が元の共有財布として扱われます。Modなしで遊んだ内容を個人財布へ自動マージする機能はありません。Mod使用と未使用を切り替える場合はテスト用セーブを分けてください。

一時停止するには `MoonWallet/disabled.txt` という空ファイルを作ってからゲームを起動します。再開時はそのファイルを削除します。

解除するにはゲームを終了し、今回追加した `version.dll` と `MoonWallet` フォルダーを削除します。元のゲームファイルを変更していないため、復元用DLLは不要です。個人財布の保存ファイルは自動削除しません。

**未確認：Windowsゲーム上での実描画、入力・フォーカス・カーソル復帰、各解像度での配置、購入／報酬処理へのフック、Steamを介した2人以上の同期、実際のセーブ／再参加。** この開発環境には実行可能なゲーム一式とWindowsがないため、動作保証済みの完成版ではありません。[実機確認手順](docs/TESTING.ja.md)で確認してください。

起動に失敗した場合は `MoonWallet/loader.log` と `MoonWallet/plugins/MoonWallet.log` を確認してください。ログにはフックの成否や保存エラーを記録し、認証情報は記録しません。

## 開発

LinuxでPython 3・venv・g++を用意して実行します。

```bash
bash tools/setup.sh
```

Windows用のコンパイラーは `ziglang==0.17.0` に固定しています。セットアップ後は以下で再ビルドできます。

```bash
ZIG="$PWD/.tools/lib/python$(.tools/bin/python -c 'import sys; print(f"{sys.version_info.major}.{sys.version_info.minor}")')/site-packages/ziglang/zig" bash tools/build.sh
bash tools/test.sh
.tools/bin/python tools/validate_artifacts.py
.tools/bin/python tests/proxy_abi_tests.py
.tools/bin/python tests/gc_handle_abi_tests.py
```

配布ZIPを作る場合は `.tools/bin/python tools/package.py` を実行します。解析元のゲームDLL・メタデータは配布物やGitに含めません。
